# Superpowers Core Philosophy & Workflow

This project adopts the [Superpowers](https://github.com/obra/superpowers) development workflow for AI agents.

## The Basic Workflow
1. **brainstorming** - Activates before writing code. Refines rough ideas through questions, explores alternatives, presents design in sections for validation.
2. **test-driven-development** - Enforces RED-GREEN-REFACTOR. Write tests before any production code.
3. **requesting-code-review** - Reviews against plan.
4. **finishing-a-development-branch** - Merges or PRs.

## Philosophy
- **Test-Driven Development** - Write tests first, always.
- **Systematic over ad-hoc** - Process over guessing.
- **Complexity reduction** - Simplicity as primary goal.
- **Evidence over claims** - Verify before declaring success.

**Important:** All AI agents working in this repository must read and follow the `.clinerules` file and utilize the skill definitions found in `.agents/skills/` to enforce this process in every iteration.
