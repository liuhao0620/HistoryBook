# 交互反馈与回合流程重构及 UI/UX 优化 (Spec)

## 为什么 (Why)
当前版本的游戏逻辑中，内政等指令是立即执行并显示结果的，这与原版《三国霸业》的设计不符，缺乏策略游戏的沉浸感和“回合制延迟反馈”的乐趣。同时，游戏的整体UI较为简陋，未能体现出“暗金/棕色调、复古策略”的美术标准，也缺乏针对鼠标和触屏的良好适配。
我们需要深度还原原版游戏的操作反馈和回合流转机制，并在此基础上全面升级美术表现。

## 做了什么改变 (What Changes)
### 1. 核心流程与反馈机制还原
- **指令队列化**: 内政、外交、军备等操作不再立即结算。下达指令时，系统会将指令推入队列，并弹出该武将的“领命”对话（如：“臣这就去开垦”）。
- **AI 演进表现**: 在玩家点击“策略结束”后，底部UI会依次显示“XXX 策略中...”，模拟其他势力的思考与行动过程。
- **回合初报告**: 进入下一回合初，系统会依次弹出上回合执行任务武将的“回报结果”对话框，展示执行成果。

### 2. UI/UX 全面优化
- 新增定制化、主题化的UI组件（GameButton, GamePanel, GameModal），替代原生的HTML元素。
- 实现全局的CSS主题，以暗金（`#cda654`）、深棕（`#1a110c`）和羊皮纸纹理为主。
- 增大触控区域（最小44x44px），以适配移动端触屏设备。
- 重构 `GameScreen` 的菜单和对话框，全面采用新的主题组件。
- 重构 `BattleScreen`，优化单位的视觉表现（使用武将头像或专属图标），改进网格交互，并增加基本的CSS动画反馈。

## 影响范围 (Impact)
- 影响的模块: 游戏核心状态机 (`useGameStore`)、指令系统、UI表现层。
- 影响的代码: `src/core/state/useGameStore.ts`, `src/core/commands/`, `src/view/screens/GameScreen.tsx`, `src/view/screens/BattleScreen.tsx`，以及新增的UI组件目录。

## 新增需求 (ADDED Requirements)
### 需求：回合报告队列机制
系统**必须**支持在回合结束时收集所有执行结果，并在回合开始时通过阻塞式UI逐一向玩家展示。
#### 场景：回合初的报告展示
- **当** 新的月份开始时
- **那么** 游戏界面被锁定，依次弹出上月派遣武将的头像及回报文本，玩家点击继续后显示下一条，直到所有报告展示完毕，玩家才能进行新一轮操作。

### 需求：AI 策略演进UI
- **当** 玩家结束回合
- **那么** 屏幕底部显示当前正在行动的AI势力名称（如“曹操 策略中...”），并带有适当的延迟感，增强回合制氛围。
