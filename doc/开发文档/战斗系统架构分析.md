## 1. 战斗地图 (Battle Map)

### 原有 C 语言结构
在 `src/baye/fight.h` 中，地图数据基于平铺(Tile)结构：
- **地图基础**: 采用 16x16 的图块，地图数据头长度 `MAP_HEAD_LEN` 为 16。
- **地形枚举 (Terrain)**: 包含 8 种主要地形：草地(`TERRAIN_LEA` 0)、平原(`TERRAIN_DENE` 1)、山地(`TERRAIN_HILL` 2)、森林(`TERRAIN_WOOD` 3)、村庄(`TERRAIN_THORP` 4)、城池(`TERRAIN_CITY` 5)、营寨(`TERRAIN_TENT` 6)、河流(`TERRAIN_RIVER` 7)。
- **行军阻力映射**: 根据不同兵种，地形被映射为特定的移动消耗（`MOV_RSTD`, `MOV_NOT`）。

### TypeScript / C# 映射

## 2. 单位类型与兵种 (Unit Types)

### 原有 C 语言结构
在 `fight.h` 及 `attribute.h` 中：
- **兵种枚举**: 共 6 种兵种：骑兵(`ARM_QIBING` 0)、步兵(`ARM_BUBING` 1)、弓箭兵(`ARM_GOBING` 2)、水军(`ARM_SHUIJUN` 3)、极兵(`ARM_JIBING` 4)、玄兵(`ARM_XUANBING` 5)。不同兵种的基础移动力（`MOV_QIBING`等）不同。
- **武将及战场属性**:
  - `PersonType`: 原始数据，含武力(`Force`)、智力(`IQ`)、体力(`Thew`)、兵种(`ArmsType`)、带兵量(`Arms`)等。
  - `JLPOS`: 战场实时位置和状态（Hp, Mp, Move, State, x, y）。
  - `JLATT`: 战斗时临时计算的攻防属性。
- **异常状态**: 正常(0)、混乱(1)、禁咒(2)、定身(3)、奇门(4)、遁甲(5)、石阵(6)、潜踪(7)、死亡(8)。

## 3. 敌人 AI (Enemy AI)

### 原有 C 语言结构
逻辑集中于 `src/FgtPkAi.c`：
- **行动目标 (`FgtGetAimPos`)**: 判断 AI 策略（进攻模式 `FGT_AT` 且非守城模式时，追击玩家主将 `g_MainGenIdx`；否则向城池 `g_CityX, g_CityY` 靠拢）。
- **寻路与移动 (`FgtCmpMove`)**:
  - 计算可移动范围内的所有点（排除不可移动点）。
  - 利用曼哈顿距离 (`FgtCntInterval`) 和该点所能造成的最大伤害 (`FgtGetHurtMax`) 进行评估。
  - 优先级：进城 > 伤害最大化 > 距离目标最近 > 地形防御加成。
- **决策树 (`FgtGetMCmdNear`)**: 依次尝试施法（`FgtJiNeng`，受智力和残兵比例影响）、普通攻击（`FgtAtkCmd`）。若皆不可行，则执行休息指令（`CMD_REST`）。

## 4. 战斗结算 (Battle Settlement)

### 原有 C 语言结构
逻辑集中于 `src/FgtCount.c`：
- **胜利判定 (`FgtCountWon`, `CountInitGen`)**:
  - 若一方兵力归零或将领全部阵亡(`STATE_SW`)，改变 `g_FgtOver` 标志 (`FGT_WON` 或 `FGT_LOSE`)。
  - 自动战斗/跳过战斗时，根据双方总兵力和粮草(`MProvender`, `EProvender`)按随机概率结算。
- **伤害公式 (`CountAtkHurt`)**:
  - 基础公式：`hurt = (at / df) * (arms / 8)`。
  - 相克加成：乘以兵种相克系数矩阵 `SubduModu`。
  - 补偿：最后 `+10`，防止双方兵力过低时出现无限平局。
- **粮草消耗 (`CountProvUse`)**: 依据兵力数量及参数 `ratioOfFoodToArmsPerDay` 每天扣减粮草。

### TypeScript / C# 映射
```csharp
public enum BattleResult {
    Ongoing = 0,    // 战斗继续
    PlayerWon = 1,  // 玩家胜利
    PlayerLose = 2, // 玩家失败
    Auto = 3        // 自动结算
}

public class BattleSettlement {
    public BattleResult Result { get; set; }
    public int PlayerRemainingArms { get; set; }
    public int EnemyRemainingArms { get; set; }
    public int PlayerRemainingProvender { get; set; }
    public int EnemyRemainingProvender { get; set; }
    
    // 扩展信息
    public int ExpGained { get; set; }
    public List<int> LootedItemIds { get; set; }
}

public class DamageCalculator {
    // 对应原版 CountAtkHurt
    public static int CalculateNormalDamage(BattleUnit attacker, BattleUnit defender, float[,] subduMatrix) {
        float baseHurt = ((float)attacker.Attack / defender.Defense) * (attacker.Arms / 8.0f);
        float subduModu = subduMatrix[(int)attacker.ArmsType, (int)defender.ArmsType];
        
        return (int)(baseHurt * subduModu) + 10;
    }
}
```
