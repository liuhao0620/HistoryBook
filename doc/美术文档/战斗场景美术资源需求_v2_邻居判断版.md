# 《三国霸业》复刻版 - 战斗场景美术资源需求 v2（邻居判断版）

本文档用于替代旧版“单张地形图重复铺设”的资源方案。新版目标是解决三类实装问题：

1. 平原、河流等基础底图拼接痕迹明显。
2. 连续森林、连续山地重复盖章感强，没有连成一片的视觉连续性。
3. 草地覆盖物不够明显，和底图混在一起。

新版采用：**无缝基础底纹 + 邻居判断 autotile + 多变体覆盖物**。

---

## 1. 全局规范

### 1.1 视角与尺寸

- 地形底图和地形覆盖物：严格 **2D 纯俯视角 top-down**，不要 isometric，不要透视，不要 3D 厚度。
- 单位角色：可继续使用 **2.5D isometric sprite**。
- 单格资源建议输出为正方形 PNG，推荐 `512x512` 或 `1024x1024`。
- 游戏运行时可缩放到 `32x32`、`64x64`、`128x128`。

### 1.2 色调

- 全部地形统一为低饱和、低对比、复古策略游戏风格。
- 主色调：暗绿、灰绿、土褐、深蓝绿、暗金、石灰色。
- 禁止高饱和亮黄、翠绿、纯蓝水面。
- 森林、山地、草地必须在平原底图上可读，但不能亮到破坏整体。

### 1.3 透明背景要求

- 基础底图：不透明 PNG。
- 覆盖物、单位、岸线、边缘过渡：透明 PNG。
- 透明资源生成时可先用纯色背景，再本地抠底。

### 1.4 文件目录

所有资源保存到：

```text
sanguobaye-web/public/assets/images/battle/
```

## 2. 地形渲染策略

### 2.1 地形层级

建议渲染顺序：

1. 基础底图层：平原或水面。
2. 岸线/边缘层：根据邻居判断叠加河岸、湖岸、海岸、森林边缘、山地边缘。
3. 地形主体层：森林内部、山地内部、草地覆盖、村庄、城池、营寨。
4. 单位层。
5. UI 层：血条、选中圈、名字、数值。

### 2.2 邻居判断

对需要连续显示的地形，渲染层必须读取上下左右以及四个斜角邻居：

```text
NW  N  NE
 W  C   E
SW  S  SE
```

最小实现可先使用四方向 bitmask：

```text
N = 1
E = 2
S = 4
W = 8
mask = N + E + S + W
```

完整实现建议使用 47-tile autotile，以处理内角和外角。

## 4. 水面邻居判断资源：河岸/海岸 autotile

- 当前格是水，旁边是陆地：在水格边缘显示岸线。

## 12. 实装修正规则：连续地形中心图与边缘图

本轮实装验证后，确认连续森林、连续山地最容易失败的原因不是邻居判断代码，而是资源语义混乱：`center` 图如果自带透明外轮廓、紫色抠图残边或完整块状边框，连续摆放时一定会像“贴纸矩阵”。

### 12.1 center 图硬性要求

适用于：

```text
wood_autotile/wood_center_01.png
hill_autotile/hill_center_01.png
```

要求：

- 必须铺满整个正方形 tile。
- 四边必须能和同类 center tile 连续拼接。
- 不允许有透明外轮廓。
- 不允许有紫色、品红、蓝色等 chroma-key 残边。
- 不允许画“外轮廓边框”或“独立贴纸阴影”。
- 森林 center 只表现连续树冠内部；山地 center 只表现连续岩脉/山体内部。

### 12.2 edge 图硬性要求

适用于：

```text
wood_autotile/wood_edge_n.png
wood_autotile/wood_edge_e.png
wood_autotile/wood_edge_s.png
wood_autotile/wood_edge_w.png
hill_autotile/hill_edge_n.png
hill_autotile/hill_edge_e.png
hill_autotile/hill_edge_s.png
hill_autotile/hill_edge_w.png
```

要求：

- edge 图必须是真正的“外轮廓补片”，不能直接复用 center 图。
- 只有指定方向允许出现外缘衰减、树冠收边、岩石收边。
- 其它方向必须能与 center 图自然拼接。
- 在没有合格 edge/corner 资源前，渲染层应只使用 center 图，避免把错误 edge 叠出块状边框。

### 12.3 草地 overlay 硬性要求

适用于：

```text
tile_lea.png
```

要求：

- 必须是真透明 PNG overlay。
- 透明像素不能在浏览器里显示出任何紫色底。
- 草地颜色以橄榄绿、灰绿、枯黄为主；紫色花点只能极少量使用，不能形成紫色区域。
- 覆盖率建议 25%-45%，避免把平原整块染色。
