# 战斗场景美术资源需求 v3（复古符号化版）

## 目标

第三版采用“原版符号化战棋地图 + 低饱和现代纹理”的方向。地图首先要清楚读图，其次才是细节丰富。不要追求照片级自然材质。

## 渲染层级

1. 地图级平原背景：`tile_base_plain.png`，连续重复铺满整张战场。
2. 水域格：使用地图对齐的 `tile_base_water.png`，每个水格按全局坐标裁切，不能每格从中心重启纹理。
3. 岸线层：水格根据 N/E/S/W 邻居叠加 `water_edges/water_edge_00..15.png`。
4. 地形主体层：森林、山地、草地、建筑。
5. 单位层。
6. UI 和交互高亮层。

常驻格线禁止显示。格子感只在 hover、移动范围、攻击范围、选中态中出现。

## 资源语义

### 基础底纹

- `tile_base_plain.png`：低噪声灰绿平原，边缘必须无缝。
- `tile_base_water.png`：低对比蓝绿水面，使用短横水纹，边缘必须无缝。

### 森林

- `wood_autotile/wood_center_01.png`：森林内部，铺满整格，可与同类连续拼接。
- `wood_autotile/wood_edge_n/e/s/w.png`：只负责指定方向的自然收边，其它方向必须能与 center 连接。

森林应像原版树林符号区域：树簇清晰、低噪声、低饱和，不要照片级树冠。

### 山地

- `hill_autotile/hill_center_01.png`：山地区域内部，铺满整格，可与同类连续拼接。
- `hill_autotile/hill_edge_n/e/s/w.png`：只负责指定方向的自然收边，其它方向必须能与 center 连接。

山地应像原版山形符号区域：山脉笔触清楚，但不要每格一个孤立大山贴纸。

### 草地和建筑

- `tile_lea.png`：透明草地 overlay，覆盖率 25%-45%，不能有紫色底。
- `tile_thorp.png`、`tile_city.png`、`tile_tent.png`：透明建筑 overlay，继续叠在平原背景上。

## 验收标准

- 平原内部看不到格线。
- 水域内部看不到格线。
- 森林和山地内部连续，外轮廓有收边，不是硬矩形。
- 地形符号清楚，噪声不抢单位和 UI。
- 构建和 `battleTerrainRendering` 测试通过。
