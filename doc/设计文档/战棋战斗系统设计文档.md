# 《三国霸业》战棋战斗系统设计文档

## 一、 系统概述
当一方对另一方的城池下达“出征”指令时，游戏将从大地图模式切换至战棋战斗模式。战斗系统是本作的核心玩法之一，采用回合制战棋（SRPG）规则。玩家需要考虑地形、天气、兵种、粮草等诸多因素，通过走位、物理攻击和计谋魔法击败敌人。

## 二、 战场环境设计
### 2.1 战场地图与地形
战斗在 16x16 像素图块拼成的网格地图上进行。每个图块代表一种地形，地形对战斗有着至关重要的影响：
- **地形种类**：草地、平原、山地、森林、村庄、城池、营寨、河流。
- **移动阻力**：不同兵种进入不同地形消耗的移动力（Move Point, MP）不同。例如：
  - 骑兵：在平原移动极快，但几乎无法穿越森林和山地。
  - 步兵/弓兵：适应性较强，阻力中等。
  - 水军：在河流中移动消耗极低，但在陆地移动缓慢。
- **防御加成**：地形为武将提供基础的物理防御乘数（TerrDfModu）：
  - 城池（CITY）：1.5 倍
  - 山地（HILL）：1.3 倍
  - 营寨（TENT）：1.2 倍
  - 森林（WOOD）：1.15 倍
  - 村庄（THORP）：1.1 倍
  - 草地（LEA）/ 平原（DENE）：1.0 倍（无加成）
  - 河流（RIVER）：0.8 倍（降低防御）
  - *注：不同兵种在不同地形上还会受到额外的攻防属性微调（地形影响表 `dFgtLandF`）。*
- **计谋影响**：地形限制了某些计谋的施放。例如，“水淹”只能对处于河流或河流周边的敌军施放。

### 2.2 天气系统
战场上具有动态的天气变化，每个回合（天）开始时有概率改变天气。
- **天气种类**：晴、阴、风、雨、冰雹。
- **对计谋的影响**：天气决定了计谋的实际威力。
  - **计谋天气系数**：每种计谋针对5种天气分别配置了不同的百分比威力系数。
  - **最终天气加成** = `技能对应天气的系数 / 100`。
  - *示例*：晴天火攻系数可能为150（即1.5倍伤害），而雨天火攻系数可能为0（无法造成伤害）；雨天水淹系数则大幅提升。风天可能会增加某些计谋的波及范围或威力。

## 三、 战斗单位（兵种）设计
参战武将最多各10名（进攻方10人，防守方10人）。武将所带的兵种决定了其在战场的定位。
- **基础兵种**：
  - **骑兵（ARM_QIBING）**：基础移动力 5。高机动，平原作战极强，但受地形限制大。
  - **步兵（ARM_BUBING）**：基础移动力 4。攻守均衡，适应各种地形。
  - **弓箭兵（ARM_GOBING）**：基础移动力 4。具有远程攻击能力，可隔空打击敌人，不被反击。
  - **水军（ARM_SHUIJUN）**：基础移动力 5。水战特化兵种。
- **高级兵种**：
  - **极兵（ARM_JIBING）**：基础移动力 6。综合能力极强的精锐。
  - **玄兵（ARM_XUANBING）**：基础移动力 3。移动缓慢但拥有特殊能力或极高攻防的重甲兵种。

### 3.1 兵种基础设定与相克机制
游戏中共有6类兵种，存在基础攻防系数差异以及复杂的相克关系（作为攻击方对防御方的伤害乘数）：
- **兵种系数与相克**：
  - **骑兵**：攻击系数 1.0，防御系数 0.7。克制步兵（1.2倍）、玄兵（1.3倍）；被弓兵（0.8倍）、极兵（0.7倍）克制。
  - **步兵**：攻击系数 0.8，防御系数 1.2。克制弓兵（1.2倍）、玄兵（1.2倍）；被骑兵（0.8倍）、极兵（0.6倍）克制。
  - **弓箭兵**：攻击系数 0.9，防御系数 1.0。克制骑兵（1.2倍）、极兵（1.1倍）、玄兵（1.2倍）；被步兵（0.8倍）克制。
  - **水军**：攻击系数 0.8，防御系数 1.1。对所有兵种物理伤害均衡（均为 1.0倍），无明显相克。
  - **极兵（精锐）**：攻击系数 1.3，防御系数 1.2。克制步兵（1.3倍）、骑兵（1.1倍）、玄兵（1.5倍）；略被弓兵（0.9倍）克制。
  - **玄兵（特殊）**：攻击系数 0.4，防御系数 0.6。物理攻防极低，对所有兵种物理伤害仅有 0.6倍，且被所有兵种克制（受到1.2~1.5倍伤害），主要依赖计谋作战。

## 四、 战斗指令与行动规则
在己方回合，玩家可对未处于“行动结束”或“异常状态（如混乱、定身）”的武将下达指令。战斗指令标志包含攻击、计谋、查看、休息等：
1. **移动（Move）**：
   - 算法：系统使用寻路算法（如广度优先搜索），根据兵种基础移动力减去沿途地形阻力，计算并高亮显示可达范围。
2. **攻击（Attack - CMD_ATK）**：
   - **普通攻击**：对攻击范围（基础为相邻1格，弓兵或装备特殊武器可达2格或以上）内的敌军发起物理攻击。
   - **伤害公式**：
     - **攻击方武力（AT）** = `(武力 * (等级 + 10) * 兵种攻击系数)` * 地形影响调节
     - **防御方防御力（DF）** = `(智力 * (等级 + 10) * 兵种防御系数)` * 地形影响调节 * 地形防御系数（TerrDfModu）
     - *注：若开启自定义比例配置，武力/智力/年龄的权重会重新分配。*
     - **基础伤害** = `(攻击方AT / 防御方DF) * (攻击方当前兵力 / 8)`
     - **最终伤害** = `基础伤害 * 兵种相克系数 + 10`（+10为保底伤害，防止双方兵力过低时出现平局无法掉血）。
3. **计谋（Magic/Skill - CMD_STGM）**：
   - 消耗武将自身的技能点（MP）。每个武将最多可携带10个技能。
   - **计谋分类**：
     - *伤害类*：火攻、水淹、滚木、雷石等，造成大量兵力损失。
     - *控制类*：使敌方陷入“混乱”（无法操作）、“定身”（无法移动）、“禁咒”（无法施法）。
     - *战术类*：潜踪（隐身）、遁甲、奇门、石阵等。
     - *恢复/辅助类*：恢复兵力、援军等。
   - **判定条件**：施放需检查目标地形是否符合、当前天气是否允许。成功率受双方智力差影响。
   - **技能伤害公式**：
     - 计谋不仅对敌方兵力造成伤害，还会对粮草造成破坏。最终伤害（兵力/粮草）的计算方式为：
     - **最终伤害** = `技能基础伤害 * (天气系数 / 100) * (目标兵种系数 / 100) * (目标地形系数 / 100) * (施法者地形系数 / 100)`
     - 计谋的威力不仅取决于技能本身的设定，还受到当前天气、敌方兵种、敌方所处地形以及施法者所处地形的四重百分比修正，体现了天时地利人和的策略深度。
4. **查看（Look - CMD_LOOK）**：
   - 查看指定图块上敌方或己方武将的详细信息。
5. **休息/待机（Rest - CMD_REST）**：
   - 结束当前武将回合，不采取行动，驻扎在原地。驻防在城池、村庄或营寨可能会有一定的恢复效果。

## 五、 胜负判定与资源消耗
- **粮草系统**：
  - 战斗最大持续 30 天（回合）。
  - 每天回合结束时，攻守双方会根据参战总兵力扣除相应粮草。
  - **因粮草战败**：若进攻方粮草归零，判定进攻失败，强制撤退；若防守方粮草归零，城池直接沦陷，判定防守失败。
- **胜利条件**：
  - 击杀敌方“主将”（兵力归零）。
  - 全歼敌军所有武将。
  - 进攻方将武将移动至敌方“城池”核心图块上（占领据点）。
  - 防守方坚守 30 天未被击败。
- **战后结算**：
  - 存活并参与战斗的武将获得经验值。满100经验升级，提升兵力上限，恢复状态。
  - 战败方（兵力归零）的武将有概率被胜方俘虏。
