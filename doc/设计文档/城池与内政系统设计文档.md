# 《三国霸业》城池与内政系统设计文档

## 一、 系统概述
城池系统是《三国霸业》大地图战略模式的基础。全国共有 38 座城池，每座城池是玩家获取资源（金钱、粮食、兵源）、调配兵力、驻扎武将的核心据点。内政系统则是玩家管理这些据点、增强势力实力的主要手段。所有的内政指令都需要消耗武将的体力。

## 二、 城池数据结构设计
每座城池在底层维护了以下详细的属性数据：
1. **基础属性**：
   - **归属（Belong）**：标识当前占领该城池的君主势力（PersonID）。
   - **太守（SatrapId）**：城池的管理者，太守的某些能力会影响城池的自然发展或防灾效果。
   - **状态（State）**：分为正常（0）、饥荒（1）、旱灾（2）、水灾（3）、暴动（4）。
     - *自然灾害*（饥荒、旱灾、水灾）会大幅降低该城池在当年的粮食或金钱收成。
     - *暴动* 会直接降低民忠，甚至引发士兵逃亡或后备兵力损耗。

2. **经济与发展属性**：
   - **农业开发度（Farming）与 农业上限（FarmingLimit）**：决定每年秋季的粮食产出。通过“开垦”指令提升。
   - **商业开发度（Commerce）与 商业上限（CommerceLimit）**：决定每年初的金钱税收。通过“招商”指令提升。
   - **防灾（AvoidCalamity）**：抵抗自然灾害的几率。通过“治理”指令提升。
   - **民忠（PeopleDevotion）**：反映百姓对势力的拥护度。影响“征兵”时的人口转化率，过低时容易发生暴动。

3. **人口与军备属性**：
   - **人口（Population）与 人口上限（PopulationLimit）**：城市总人口。征兵会消耗人口，人口会随时间自然缓慢增长。
   - **金钱（Money）**：势力的通用货币，用于宴请武将、招商、征兵等开销。
   - **粮食（Food）**：军队出征时的必需品，战斗中会按天数和兵力规模持续消耗。
   - **后备兵力（MothballArms）**：由人口征召而来，但尚未分配给武将的预备役士兵。

4. **列表属性**：
   - **人才队列（PersonQueue）**：当前驻扎在城池内或属于该城池的武将集合。
   - **道具队列（ToolQueue）**：该城池内尚未分配给武将的闲置装备/道具集合。

## 三、 指令系统设计
玩家可以在大地图上对己方城池下达指令，每个指令需指派一名武将执行。指令的执行效果受执行武将的能力（武力、智力）显著影响。

在操作界面中，指令被划分为三大类：**内政**、**外交**、**军备**。本部分主要说明内政与军备相关的指令。

### 3.1 内政指令
内政指令涵盖了城池发展、人事管理、物资调配等功能。

- **开垦（Assart）**：
  - **作用**：提升农业开发度。
  - **逻辑**：消耗50金钱和4体力。农业提升值 = `(智力 / 10) * (随机 2~5) + (智力 / 2)`。开发度不能超过城池农业上限。
- **招商（Accractbusiness）**：
  - **作用**：提升商业开发度。
  - **逻辑**：消耗50金钱和4体力。商业提升值 = `(智力 / 10) * (随机 2~5) + (智力 / 2)`。不能超过商业上限。
- **搜寻（Search）**：
  - **作用**：在城池内搜寻在野武将、道具、金钱或粮草。
  - **逻辑**：消耗10金钱和4体力。
    - 首先有25%概率触发“人才/道具”判定，若随机值小于执行武将的智力，则有50%概率搜寻**在野武将**（若成功招募，其忠诚度变为70~99），50%概率搜寻道具。
    - 若未搜寻到人才/道具，则有20%概率找到 `10+随机(智力*2)` 金钱，20%概率找到粮草，否则一无所获。
- **治理（Father）**：
  - **作用**：提升城池的防灾能力。
  - **逻辑**：消耗20金钱和4体力。防灾提升值 = `1 + 随机 4`。
- **出巡（Inspection）**：
  - **作用**：安抚百姓，提升民忠，并增加人口。
  - **逻辑**：消耗20金钱和4体力。民忠提升值 = `1 + 随机 4`。每次出巡增加100人口。
- **招降（Surrender）**：
  - **作用**：说服被俘虏的敌方武将归顺。
  - **逻辑**：成功率 = `(执行者智力 - 目标智力) + 50`。成功后俘虏忠诚变为 40~80，并加入我方。
- **处斩（Kill）**：
  - **作用**：处决俘虏。
  - **逻辑**：被处斩武将直接死亡。
- **流放（Banish）**：
  - **作用**：释放俘虏或驱逐己方武将。
  - **逻辑**：目标武将变成在野状态。
- **赏赐（Largess）**：
  - **作用**：提升武将忠诚度。
  - **逻辑**：消耗50金钱，忠诚度+8（最高100）。
- **没收（Confiscate）**：
  - **作用**：剥削武将增加金钱。
  - **逻辑**：获得50金钱，该武将忠诚度下降20点。
- **交易（Exchange）**：
  - **作用**：买卖粮食。
  - **逻辑**：买入比例 1金:5粮；卖出比例 1粮:2金。立即生效。
- **宴请（Treat）**：
  - **作用**：恢复武将体力，并微弱提升忠诚度。
  - **逻辑**：消耗50金钱，恢复满体力，忠诚度+1（最高100）。
- **输送（Transportation）**：
  - **作用**：城际资源调配。
  - **逻辑**：**非立即生效（有延迟）**。转移钱粮兵力至己方其他城市，需等待一定月数。
- **移动（Move）**：
  - **作用**：武将调防。
  - **逻辑**：**支持多目标选择**且**有延迟**。可同时派遣多名武将移动至己方其他城市，需等待一定月数。

### 3.2 军备指令
军备指令专注于军事准备、侦察和对外出征。

- **侦察（Reconnoitre）**：
  - **作用**：获取情报。
  - **逻辑**：**有延迟**。消耗金钱和体力，获取目标城市的详细数据，需等待1个月。
- **征兵（Conscription）**：
  - **作用**：将金钱转化为后备兵力。
  - **逻辑**：获得兵力 = `min(民忠 * 10, 金钱 * 2)`，消耗金钱 = `兵力 / 2`。
- **分配（Distribute）**：
  - **作用**：调整兵力归属。
  - **逻辑**：**支持多目标选择**。可立刻将城池后备兵力补充给多位武将。
- **掠夺（Depredate）**：
  - **作用**：强行榨取城池资源。
  - **逻辑**：获得粮食 = `(智力+武力)*5`，金钱 = `(智力+武力)*2`。代价是城市民忠、农业、商业减半。
- **出征（Battle）**：
  - **作用**：对敌方城池发起攻击。
  - **逻辑**：切入战棋战斗界面，双方派兵对决。

## 四、 资源结算与刷新机制
- **体力恢复**：所有武将每月自动恢复固定体力（如4点），或通过城池内的“宴请”指令大幅恢复（如50点，消耗金钱）。
- **资源产出**：
  - 每年特定月份（如1月收税，7月收粮），系统遍历所有城池，根据商业和农业开发度结算金钱和粮食并加入城池库存。
  - 产出结算时会触发灾害概率判定。若触发水灾/旱灾，则当季产出大幅减少。
